## Zero-Cost Live Deployment (GitHub + WordPress Playground)
1. Push **this directory** (`aerocore-apex/`) to a public GitHub repository (e.g. `https://github.com/<YOUR_USER>/aerocore-apex`).
2. Replace `YOUR_GITHUB_USER` in `blueprint.json` with your GitHub username.
3. Share your live $0 WordPress demo URL:
   `https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/<YOUR_USER>/aerocore-apex/main/blueprint.json`
